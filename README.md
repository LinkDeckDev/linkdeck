# LinkDeck

LinkDeck is a compact, touch-first digital identity and sharing device built around an ESP32-S3, AMOLED display and NFC.

This repository is the **public project overview**.

## Current Status

Prototype v2 / P0 mechanical validation.

## Project Goals

- Compact digital identity device
- NFC and QR sharing
- Touch-first user interface
- Creator, developer and business profiles
- Clean and minimal industrial design
- Developer-friendly ecosystem over time
