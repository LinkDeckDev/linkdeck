# Security

Please do not disclose suspected security issues publicly.

## Reporting a security issue

Send security reports to **linkdeck.official@gmail.com** with the subject line `LinkDeck Security Report`.

Please include, where possible:

- a clear description of the issue;
- the affected public page, repository, feature or component;
- steps to reproduce the issue;
- the potential impact;
- screenshots or logs that do not contain secrets or unnecessary personal data.

Do **not** include passwords, API keys, private keys, recovery codes, authentication tokens or other secrets in public issues, discussions or pull requests.

Please avoid publicly disclosing a suspected vulnerability before LinkDeck has had a reasonable opportunity to review it.

LinkDeck is currently a prototype project. Security-sensitive production implementation details, credentials and provisioning material remain private.
